## 1. 機能概要

### 目的・背景

身内グループ内でお気に入りの飲食店情報を登録・共有・検索できるモバイルアプリ。
Googleマップ等のリンクからの簡易登録、ジャンル・エリアでの検索、グループ単位での共有を主要機能とする。

### スコープ

- [x] お店の登録・共有・検索（リンク入力 / 手動入力）
- [x] グループ管理（作成・招待コード・メンバー管理）
- [x] ランク機能（点数なし）
- [x] マップ表示
- [x] 行きたいリスト（個人、シンプルな実装）
- [x] ソーシャルログイン（Google / Apple）
- [ ] 外部リストインポート（Nice-to-have、Google Takeout等）
- [ ] Webアプリ版（Nice-to-have）

## 2. 機能要件

### ユースケース一覧

| ID | ユースケース名 | 概要 | 優先度 |
|----|----------------|------|--------|
| UC01 | お店を登録する | GoogleマップのリンクからURL入力で情報を取得、または手動で店名・エリア・ジャンル・コメント・写真・おすすめメニューを入力して登録 | 必須 |
| UC02 | お店を検索する | 食事ジャンル・飲み物ジャンル・エリアで絞り込み。行った/行ってないフィルタ（個人ベース）。複数条件のAND/OR検索に対応 | 必須 |
| UC03 | お店にランクをつける | 登録したお店にランク（点数ではない）を設定する | 必須 |
| UC04 | グループを管理する | グループの作成、有効期限付き招待コードの生成、メンバーの招待。1ユーザーが複数グループに参加可能（Discordライク）。アカウント作成時に個人用の「マイスペース」グループを自動作成（自分だけのお店記録用） | 必須 |
| UC05 | 登録されたお店を確認する | 自分または他のユーザーがグループに登録したお店を表示する。新規参加メンバーも過去のお店情報をすべて閲覧可能 | 必須 |
| UC06 | マップでお店を確認する | 登録済みのお店をマップ上にピン表示し、位置を視覚的に確認できる | 必須 |
| UC07 | 行きたいリストに保存する | 個人でお店をブックマークとして保存。シンプルな実装でOK | 必須 |
| UC08 | ユーザー登録・ログインする | Google / Apple アカウントでのソーシャルログイン | 必須 |
| UC09 | おすすめメニューを管理する | メニュー名と写真を紐づけて登録できる | 必須 |
| UC10 | 外部リストをインポートする | Google Takeoutのエクスポートファイル等からお店データを一括取込 | Nice-to-have |

## 3. 画面・UIイメージ

### 画面一覧

| # | 画面名 | 主な機能 |
|---|--------|----------|
| 1 | ログイン / サインアップ | Google / Apple ソーシャルログイン |
| 2 | ホーム（お店一覧） | グループのお店一覧表示、検索・フィルタ（ジャンル、エリア、行った/行ってない、AND/OR） |
| 3 | お店詳細 | 写真、ジャンル、コメント、おすすめメニュー（写真付き）、ランク、マップ上の位置、外部リンク |
| 4 | お店登録 | リンク入力（情報自動取得）/ 手動入力フォーム |
| 5 | マップ | 登録済みお店のピン表示、タップで詳細へ遷移 |
| 6 | グループ一覧・管理 | 参加中グループの切替、グループ作成、招待コード生成 |
| 7 | マイページ | 行きたいリスト、プロフィール設定 |

### 画面遷移・操作フロー

```
ログイン → ホーム（お店一覧）
                ├── お店詳細 → 編集
                ├── お店登録（リンク or 手動）
                ├── マップ → お店詳細
                ├── グループ管理 → 招待コード生成
                └── マイページ → 行きたいリスト
```

## 5. 非機能要件

- **パフォーマンス**: お店の登録・検索のレスポンスが快適なこと（目安: 1秒以内）
- **セキュリティ**: ソーシャルログインによる認証。グループ外ユーザーにはお店情報を非公開
- **可用性**: 24時間365日稼働（厳しいSLAは不要、サーバレス構成を設計で検討）

## 6. 外部連携

| 連携先 | 用途 | 備考 |
|--------|------|------|
| Google Maps API | マップ表示、位置情報取得 | または OpenStreetMap（無料）。設計で決定 |
| Googleマップ / 食べログのリンク | リンクからのお店情報取得 | URLパース + スクレイピングまたはAPI |
| Google / Apple 認証 | ソーシャルログイン | AWS Cognito or Firebase Auth 等 |
| Google Takeout | 保存リストインポート | Nice-to-have。GeoJSONファイルのアップロード |

## 7. 受け入れ条件 (Acceptance Criteria)

### 必須

- [ ] Google or Apple アカウントでログインできること
- [ ] お店をGoogleマップのリンク入力 or 手動入力で登録できること
- [ ] 登録時にメニュー名と写真を紐づけて保存できること
- [ ] グループを作成し、有効期限付き招待コードでメンバーを追加できること
- [ ] 1ユーザーが複数グループに参加でき、グループを切り替えて閲覧できること
- [ ] 登録したお店がグループメンバー全員に共有されること
- [ ] 新規参加メンバーが過去のお店情報をすべて閲覧できること
- [ ] 食事ジャンル・飲み物ジャンル・エリアで検索・絞り込みができること
- [ ] 行った/行ってないで絞り込みできること（個人ベース）
- [ ] 複数条件でのAND/OR検索ができること
- [ ] お店にランクをつけられること
- [ ] マップ上に登録済みお店がピン表示されること
- [ ] 行きたいリストにお店を個人で保存できること

### Nice-to-have

- [ ] Google Takeoutファイルからお店データをインポートできること
- [ ] Webアプリからもアクセスできること
